## Contract

- Map family: **home-island**
- World diameter **1024 m**, character **2.0 m**, mountain peak **20 m**
- Nature: organized + realistic CDN only — **no Quaternius megakit**
- Harvest regen **4 hours**
- Physics: **Rapier only**. Render: **Three r184 + R3F**
